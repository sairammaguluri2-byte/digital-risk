## ⚡ New Features & Enhancements

### 1. Custom Domain Check Button & Live Verification
- **Drop Any Link:** Input any URL or link (e.g. `https://mybrand.com/app`, `www.crypto-pay.org`, or `security.apexpay.com`).
- **Automatic Sanitization:** Automatically cleans protocols (`https://`), prefixes (`www.`), subpaths, and query strings.
- **Dedicated "Run Custom Domain Check" Button:**
  - Queries authoritative DNS nameservers and validates CNAME / TXT challenges.
  - Updates the primary protected host immediately.
  - Displays a green **`Verified & Active`** status badge with real-time verification timestamp.
  - Updates the DNS records table with domain-specific `TXT` challenges, `CNAME` endpoints, and `DMARC` policies.

### 2. Interactive Mobile Layout Switcher & Responsive Design
- **1-Click Mobile Preview:** Click the **`[Mobile Layout]`** toggle in the top navbar to instantly test and preview the phone layout directly in any desktop browser.
- **Phone Optimized (`< 768px`):** On mobile devices, tables automatically transform into touch-friendly cards with instant action buttons.

### 3. Unified Design Rules Enforced
- Exactly **one font pair**: Cinzel + Plus Jakarta Sans.
- Strictly **two brand colors**: Obsidian Black + Champagne Gold.
- **One button per section**, using the identical luxury champagne gold style everywhere.
